# Terrain Generator for Empires Mod

A procedural terrain generator that creates playable displacement maps for Empires Mod.

## Features
- ✅ **Procedural Terrain**: Generates mountains and valleys using noise and erosion.
- ✅ **Custom Heightmaps**: Optionally load your own grayscale PNG images as terrain.
- ✅ **Game Ready**: Automatically places bases, resource nodes, and player spawns.
- ✅ **Easy Compile**: Built-in support for VBSP to build and deploy maps to the game.
- ✅ **Customizable**: Change textures, skyboxes, and terrain shapes via config files.

## How to Use
1. Run `TerrainGenerator.exe`.
2. Select a **Preset** or adjust the **Seed** and **Size**.
3. Point the tool to your **Empires** folder (it usually finds it automatically).
4. Click **Generate** to create the map files.
5. Click **Compile** to build the map and install it to the game.

## Requirements
- ✅ **Windows 10/11** or **Linux** (via Wine)
- ✅ **Empires Mod** installed on Steam
