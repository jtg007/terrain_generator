# Plan: Separate Clear Radius for Base Areas and Resource Nodes

## Goal
- Make "Clear Radius" slider control ONLY base area flattening
- Add new "Resource Node Clear Radius" slider for resource node areas

## Completed Changes (done in previous session)
- config_model.py: Added `resource_clear_radius: int = 256` field ✅
- terrain_spec.py: Added `resource_clear_radius: int = 256` field ✅
- terrain_pipeline.py: Changed to use `spec.resource_clear_radius` instead of `base_clear_radius * 0.5` ✅
- terrain_generator.py: Added new "Resource Clear" slider (range 0-4096, default 256) ✅

## ISSUE FOUND: Preview doesn't update visually
**Problem:** The GUI sliders now work, but changing Resource Clear slider doesn't update the visual circles around resource nodes in the editor/preview. This is because:

1. Nodes get their radius only at creation time
2. Editor doesn't read radii from config_model
3. No refresh mechanism when sliders change

**Root cause locations:**
- `editor_widget.py` line 220: Base nodes created with `DEFAULT_BASE_CLEAR_RADIUS` (512)
- `editor_widget.py` line 223: Resource nodes created with hardcoded `256` (not dynamically updated)
- `preview_widget.py` line 220: Similar issue

## Required Fix

### Plan A: Dynamic radius update (preferred)
Add a method in editor_widget.py to update all node radii from config, then call it when sliders change.

1. **editor_widget.py**: Add method `def update_clear_radii(base_radius, resource_radius)`:
   - Iterate all VisualNode items in scene
   - For BASE nodes: set `clear_radius = base_radius`
   - For RESOURCE/WILDERNESS nodes: set `clear_radius = resource_radius`
   - Call `update()` on each node to trigger redraw

2. **terrain_generator.py**: Connect sliders to call this method:
   - After slider value changes, call `self.editor_widget.update_clear_radii()`
   - Query radii from `config_model.base_clear_radius` and `config_model.resource_clear_radius`

### Alternative Plan B: Use config values at creation time
Change the hardcoded 256 in editor_widget.py to read from config. But this doesn't help when slider changes after nodes are created.
